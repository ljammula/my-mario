# my-mario — Project Instructions

## Branching

Before implementing any new feature, always create and switch to a feature branch:

```
git checkout -b feature/<short-description>
```

- Use kebab-case for the description (e.g., `feature/enemy-collision`, `feature/fireball-physics`)
- Keep descriptions short — 2–4 words
- Base all feature branches off `main` unless told otherwise
- Never implement features directly on `main`
